# BlackNight — Portfolio

Portfólio pessoal profissional de **BlackNight**, desenvolvedor Python focado em bots, sistemas e automações para Discord.

## Tecnologias

- HTML5
- CSS3
- JavaScript (vanilla)
- [Lucide Icons](https://lucide.dev)
- Google Fonts (Inter + JetBrains Mono)

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub (ex: `blacknight` ou `username.github.io`)
2. Faça upload de todos os arquivos desta pasta para a raiz do repositório
3. Vá em **Settings → Pages**
4. Em **Source**, selecione a branch `main` (ou `master`) e a pasta `/ (root)`
5. Salve e aguarde alguns minutos
6. Seu site estará disponível em `https://seu-usuario.github.io/nome-do-repo`

## Estrutura

```
/
├── index.html
├── style.css
├── script.js
├── assets/
│   └── favicon.svg
└── README.md
```

## Personalização

- Edite os textos e links diretamente no `index.html`
- Cores e estilos em `style.css` (variáveis CSS no `:root`)
- Animações e interações em `script.js`
